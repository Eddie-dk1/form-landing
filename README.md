# FORM

Сайт: https://eddie-dk1.github.io/form-landing/

Репозиторий: https://github.com/Eddie-dk1/form-landing


Интерактивный учебный лендинг о коротких тренировках. Основной инструмент — Codex.

## Статус

Готовый интерактивный лендинг. Публикация одобрена пользователем 3 ноября 2026 года.

## Запуск

Требуется Node.js 22.18+ или 24+. Проверено на Node.js 25.8.1.

```sh
npm ci
npm run dev -- --port 5173 --strictPort
```

Открыть http://127.0.0.1:5173/. После остановки сервера повторить команду запуска.

```sh
npm test
npm run build
npm run preview
```

Сборка — в `dist/`. Относительные пути поддерживают подпапку GitHub Pages.

## Возможности

- Пять секций с единой спортивной арт-дирекцией и адаптивной композицией.
- Шесть программ: 10, 20 или 30 минут; дома или на улице.
- Разминка, четыре упражнения, спокойное завершение; сумма этапов совпадает с выбранной длительностью.
- Подсказки к упражнениям, доступные нажатием и с клавиатуры.
- Таймер: запуск, пауза, продолжение, сброс и повтор после завершения.
- Текущий этап и его оставшееся время. Смена программы сбрасывает занятие.
- Синхронизация переключателей первого экрана и плана.
- Расчёт реально прошедшего времени по монотонным часам.
- Видимый фокус, нативные radio, объявления состояния для скринридера, reduced-motion.

Нет регистрации, сервера, аналитики и платного AI API. Планы — демонстрационный контент учебного концепта. Сайт не отправляет данные посетителей.

## Инструменты и материалы

**Codex** — концепция, код, логика и проверка. Встроенная генерация изображений — макеты секций и отдельные изображения. Vite, TypeScript, CSS; Node.js test runner; Sharp для оптимизации WebP.

Sofia Sans Extra Condensed и Roboto Condensed хранятся локально. Лицензии SIL OFL находятся в `public/fonts/`. Изображения сгенерированы; спортсменка не является реальным амбассадором. Текст и управление — живой HTML.

- `concepts/` — три исходных направления; `concepts/form/` — референсы секций FORM.
- `docs/prompts.json` и `docs/form-generation-prompts.json` — точные промпты генерации.
- `docs/form-art-direction.md` — разбор выбранной визуальной системы.
- `docs/qa.md` и `docs/screenshots/` — результаты проверки и скриншоты.

## Публикация

GitHub Actions запускает тесты, собирает сайт и публикует dist/ через GitHub Pages при обновлении ветки main. Конфигурация — .github/workflows/pages.yml.

Бесплатный хостинг — GitHub Pages, платный домен не нужен.
