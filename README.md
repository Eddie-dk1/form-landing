# FORM

[Открыть сайт](https://eddie-dk1.github.io/form-landing/)

## Идея

Лендинг о коротких тренировках, которые помещаются в повседневный график. Пользователь выбирает время и место занятия, получает план и запускает таймер. Визуальный стиль — спортивный плакат: крупная типографика, молочный фон, чёрно-белый силуэт и оранжевый акцент.

## Технологии

- Vite, TypeScript, HTML, CSS и SVG.
- Node.js Test Runner для тестирования логики.
- Sharp для оптимизации изображений в WebP.
- GitHub Actions и GitHub Pages для сборки и публикации.

## Возможности

- Шесть программ: 10, 20 или 30 минут; дома или на улице.
- Разминка, четыре упражнения и завершение с общей длительностью выбранной программы.
- Таймер с текущим этапом, запуском, паузой, продолжением, сбросом и повтором.
- Подсказки к упражнениям и синхронизация переключателей первого экрана с планом.
- Адаптивная вёрстка, управление клавиатурой и поддержка prefers-reduced-motion.

Сайт статический. Планы тренировок хранятся локально; сервер и внешние API не требуются.

## Запуск

Требуется Node.js 22.18+ или 24+.

```sh
npm ci
npm run dev -- --port 5173 --strictPort
```

Локальный адрес: http://127.0.0.1:5173/.

```sh
npm test
npm run build
npm run preview
```

Production-сборка создаётся в dist/. Относительные пути поддерживают размещение в подпапке хостинга.

## Структура

- src/main.ts — интерфейс и обработка действий.
- src/workout.ts — программы тренировок.
- src/timer.ts — логика таймера по монотонным часам.
- src/style.css и src/viewport.css — оформление и адаптивность.
- public/assets/ — изображения WebP.
- public/fonts/ — локальные шрифты Sofia Sans Extra Condensed и Roboto Condensed, лицензии SIL OFL.
- tests/ — тесты программ и таймера.
- docs/ — техническая документация и результаты проверки.

## Публикация

При push в main GitHub Actions устанавливает зависимости, запускает тесты, собирает сайт и публикует dist/ через GitHub Pages. Конфигурация — .github/workflows/pages.yml.
